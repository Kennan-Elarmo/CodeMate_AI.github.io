# CodeMate AI

### Your Personal AI-Powered Coding Tutor

## About the Project

**CodeMate AI** is a beginner-friendly programming learning platform designed to help students understand coding concepts, practice programming, and improve their problem-solving skills. It provides an interactive learning environment where users can explore programming lessons, answer coding exercises, track their learning progress, and interact with a virtual AI tutor.

The goal of CodeMate AI is to make learning programming easier, more accessible, and more enjoyable for beginners.

## Features

- **AI Tutor Chat** – Provides programming explanations and answers to common coding questions.
- **Programming Lessons** – Offers beginner-friendly lessons and examples.
- **Coding Practice** – Allows users to practice basic programming exercises.
- **Progress Tracking** – Monitors completed lessons and earned XP points.
- **Dashboard** – Displays learning progress and activities.
- **Language Selection** – Allows users to select their preferred programming language.
- **Level Selection** – Supports different learning levels.
- **Interactive Interface** – Provides a simple and user-friendly design.

## Technologies Used

The project uses the following technologies:

- **HTML5** – For the structure and content of the website.
- **CSS3** – For styling, colors, layouts, and responsive design.
- **JavaScript** – For interactive features and website functionality.
- **Bootstrap 5** – For responsive layouts and interface components.
- **Bootstrap Icons** – For website icons.
- **LocalStorage** – For saving learning progress in the browser.

## How to Install and Run

1. Download or clone the project.
2. Extract the project folder if it is compressed.
3. Open the project folder in Visual Studio Code.
4. Make sure the CSS and JavaScript files are inside their correct folders.
5. Open `index.html` using your web browser or Visual Studio Code Live Server.
6. Start exploring the CodeMate AI learning platform.

## How to Use

1. Open the CodeMate AI homepage.
2. Navigate through the available programming lessons.
3. Select a programming language and learning level.
4. Read the lesson descriptions and examples.
5. Use the AI Tutor section to ask programming questions.
6. Complete the coding practice activities.
7. Monitor your progress and XP points through the dashboard.

## Important Note

The current version of CodeMate AI uses JavaScript-based sample responses for its AI Tutor demonstration. It does not yet connect to a live AI API. The coding practice and progress tracking features are also implemented as browser-based demonstrations.

A live AI integration and additional programming languages may be added in future versions.
